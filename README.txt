TRAFFIC SURVEY APP - Paano patakbuhin sa VS Code
================================================

Mga file:
- index.html  - ang pangunahing pahina
- style.css   - ang mga kulay at itsura (design)
- script.js   - ang logic (kalkulasyon at Download Word)

Paano i-run:
1. I-download ang buong folder na ito.
2. I-extract kung naka-ZIP.
3. Buksan ang folder sa VS Code (File > Open Folder).
4. I-double click ang index.html para bumukas sa browser,
   O i-install ang "Live Server" extension sa VS Code,
   i-right click ang index.html at piliin ang "Open with Live Server".

Kailangan ng internet para sa magandang font (IBM Plex).
Kung walang internet, gagana pa rin ang app gamit ang ordinaryong font.

Ano ang ginagawa ng app:
- Traffic survey counting (AM/PM, movements)
- Convert to Actual (2026 bilang base year)
- Download Word: isang file na may 2026 hanggang 2076 (51 years),
  bawat year may sariling page na kumpleto ang AM at PM tables.
